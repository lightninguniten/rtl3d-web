================================================================
 RTL3D Lightning Quiz -> Google Sheet
================================================================

Every attempt becomes one row in a Google Sheet:

  Timestamp | Name | School/University | Score | Total | Percent | Q1 | Q2 | ...

The Q columns record what each person picked, so you can see which
questions people get wrong, not just the total. A right answer is the
letter on its own ("B"). A wrong answer is written "A -> C", meaning
they picked A and the correct option was C.

The script itself lives in ONE place:  tools/quiz-sheet.gs
Do not keep a second copy in this file - that is how the deployed script
drifted out of date before.


----------------------------------------------------------------
ALREADY SET UP, BUT THE RESULTS PAGE IS EMPTY?
----------------------------------------------------------------
That means the deployed script is an old version. Check it by opening
the endpoint from js/quiz-config.js in a browser. You should see JSON.
If you see "Script function not found: doGet", go straight to STEP 3
and deploy a NEW VERSION of the existing deployment. Do not create a
new deployment - that changes the URL.


----------------------------------------------------------------
STEP 1 - Create the Sheet (skip if you already have one)
----------------------------------------------------------------
1. Go to https://sheets.google.com and create a blank spreadsheet.
2. Name it "RTL3D Quiz Results" - the name matters only so you can find
   it again in Drive later. Write the URL down somewhere; nothing in
   this project records which Sheet is in use.
3. No header row needed. The script writes it.


----------------------------------------------------------------
STEP 2 - Add the Apps Script
----------------------------------------------------------------
Run this from the project root:

    tools\setup-quiz-sheet.ps1

It copies tools/quiz-sheet.gs to your clipboard and opens Apps Script.
Then:

1. In your Sheet, click  Extensions > Apps Script.
2. Select all the existing code and delete it.
3. Paste (Ctrl+V) and save.

(If you would rather not run the script: open tools/quiz-sheet.gs in an
editor and copy the whole file by hand. Same thing.)


----------------------------------------------------------------
STEP 3 - Deploy as a Web App
----------------------------------------------------------------
FIRST TIME:
1. Deploy > New deployment.
2. Gear next to "Select type" > Web app.
3. Set:
      Description:      RTL3D quiz
      Execute as:       Me
      Who has access:   Anyone          <-- required, the site is public
4. Deploy, and authorise when prompted.
5. Copy the Web app URL:
      https://script.google.com/macros/s/AKfycb..../exec

EVERY TIME AFTER THAT:
   Deploy > Manage deployments > (pencil) Edit > Version: New version
   > Deploy.
   This keeps the same URL. Editing the code alone changes nothing that
   is live - the deployment is a snapshot, so you must cut a new version.


----------------------------------------------------------------
STEP 4 - Point the site at it (first time only)
----------------------------------------------------------------
1. Open  js/quiz-config.js
2. Put the Web app URL between the quotes:
      window.RTL3D_QUIZ_ENDPOINT = 'https://script.google.com/macros/s/AKfyc..../exec';
3. Optionally put the Sheet's own URL in RTL3D_QUIZ_SHEET_URL so the
   results page can link to it even when the endpoint is down.
4. Save, commit, push.


----------------------------------------------------------------
STEP 5 - Check it actually works
----------------------------------------------------------------
Do not skip this. The quiz cannot tell you whether saving succeeded:
it posts with mode:'no-cors', so the browser hides the response. The
page says "Result submitted" because the request left the device, not
because the Sheet accepted it.

1. Open the endpoint URL directly. Expect JSON, including sheetUrl.
2. Take the quiz once with a name like "TEST".
3. Look at the Sheet. A row should be there. Delete it afterwards.
4. Open  /quiz-results/  - it should say "Google Sheet" as the source.
   If it says "this browser", the deployment is still stale: STEP 3.


----------------------------------------------------------------
Notes
----------------------------------------------------------------
- Export: in the Sheet, File > Download > CSV (or .xlsx).
- Results are ALSO kept in the visitor's own browser as a backup. On a
  kiosk, dump them from the browser console on the quiz page:
      RTL3D_QUIZ.exportCsv()
  That export includes the per-question columns too.
- Adding a question to the quiz needs no change here. The script reads
  however many q1, q2, ... fields arrive and widens the header itself.
- Anyone who views the page source can see the endpoint and post rows to
  it. That is unavoidable for a public static site - the browser has to
  know the URL. Treat the Sheet as open to tampering, and sanity-check
  the rows before quoting numbers anywhere that matters.
